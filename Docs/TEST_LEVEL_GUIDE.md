# Boyscamp Simple Test Level

## How to use
1. Create a new empty scene called `TestLevel`
2. Add an empty GameObject and attach the script `TestLevelBootstrap`
3. Press Play

The script will automatically create:
- A ground plane
- A player capsule with movement
- Camera follow

## Controls
- WASD → Move
- Mouse → Look
- Left Shift → Sprint
- Space → Jump

This gives you something playable while we continue building the real game.
