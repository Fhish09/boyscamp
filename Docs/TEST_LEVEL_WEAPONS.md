# Test Level - Weapons & HUD

## New Scripts
- SimpleWeapon.cs → Basic shooting + reload
- SimpleHealth.cs → Health system
- SimpleHUD.cs → Ammo and health display

## How to test
1. Open TestLevel scene
2. Select the Player object
3. Add the SimpleWeapon script
4. Add SimpleHealth script
5. Create a simple UI Canvas with Text for ammo and health
6. Assign references in SimpleHUD

Controls:
- Left Mouse Button → Shoot
- R → Reload
