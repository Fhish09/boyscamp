# Boyscamp Characters

## Fhish (Default / Creator Character)

**Title:** Lone Wolf  
**Active Skill - Shadow Step**
- Instantly dash a short distance
- Breaks enemy aim assist for 2 seconds
- Cooldown: 25 seconds

**Passive Skill - Hunter's Instinct**
- After knocking down an enemy, movement speed increases by 10% for 5 seconds
- Slight reload speed increase (to be fully implemented later)

**Personality**
- Cold and focused
- Rarely speaks
- Prefers stealth over direct combat
- Acts like a lone wolf but protects teammates when it matters

**Voice Lines**
- "Stay out of my way."
- "Target acquired."
- "One shot. One chance."
- "You never saw me coming."

## How to use
1. Create CharacterData assets in Unity (Right click → Create → Boyscamp → Character Data)
2. Assign the data to the PlayerCharacter component
3. Skills are automatically added for Fhish
