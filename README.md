# Boyscamp

School-themed Battle Royale game inspired by CODM / Warzone.

## Maps
- CCSS Nkolmbong (Main BR)
- SAJOCCOL Afanayo (Blackout)
- Campus Clash (50 players)

## Features
- Battle Royale + Multiplayer modes
- Characters (Fhish main)
- Weapons, vehicles, killstreaks
- Progression system (Form 1 → Upper Sixth)
- Clans, voice chat, battle pass
